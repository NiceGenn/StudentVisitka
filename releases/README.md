# Релизы

Готовые к публикации архивы сайта. Каждый распаковывается в корень хостинга
и работает без настройки: ни PHP, ни базы, ни правил переписывания URL.

| Версия | Что нового | Архив |
| --- | --- | --- |
| 1.5.0 | «Структура» генерируется из справочника, добавлен сам справочник | `visitka-student-v1.5.0.zip` |
| 1.4.1 | Поправлено затемнение баннера — фотография снова видна | `visitka-student-v1.4.1.zip` |
| 1.4.0 | Новое оформление: светлая шапка, сине-стальная палитра | `visitka-student-v1.4.0.zip` |
| 1.3.0 | Перестроена структура репозитория, сохранён исходный архив | `visitka-student-v1.3.0.zip` |
| 1.2.0 | Цвета вынесены в переменные, одиннадцать готовых схем | `visitka-student-v1.2.0.zip` |
| 1.1.0 | Раздел «Визитница»: 42 карточки подразделений | `visitka-student-v1.1.0.zip` |
| 1.0.0 | Первая версия: структура репозитория и сборка | `visitka-student-v1.0.0.zip` |

Те же архивы лежат во вкладке [Releases](https://github.com/NiceGenn/VisitkaStudent/releases)
на GitHub — там их создаёт workflow при пуше тега `v*`.

## Собрать свежий архив

```bash
./tools/build.sh          # версия берётся из CHANGELOG.md
./tools/build.sh 1.3.0    # или задаётся явно
```

Скрипт кладёт сюда `visitka-student-v<версия>.zip` и заодно проверяет, что
все внутренние ссылки и ресурсы на месте.
