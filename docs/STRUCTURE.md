# Устройство сайта

Документ описывает, из чего состоит сайт и какие решения приняты при
переносе исходников в репозиторий.

## Страницы

Все восемь страниц самостоятельны: каждая содержит полную разметку шапки,
навигации и подвала. Общего шаблона и сборщика нет, поэтому правка меню
или контактов в шапке — это правка во всех восьми файлах.

| Файл | Раздел | Особенности |
| --- | --- | --- |
| `index.html` | Главная | Баннер с фото города, шесть карточек отделов, три новости, быстрые ссылки |
| `about.html` | Об администрации | Фотография руководителя (`bashun.jpg`) |
| `structure.html` | Структура | Самая объёмная страница, полный перечень подразделений |
| `services.html` | Услуги | Муниципальные услуги |
| `news.html` | Новости | Единственная страница, подключающая `script.js` |
| `schools.html` | Школы и сады | Перечень образовательных учреждений |
| `docs.html` | Документы | Ссылки на внешние файлы `.docx` на blagraion.ru |
| `contacts.html` | Контакты | Встроенная карта Яндекса через iframe |

## Стили

`src/assets/css/style.css` — общая часть: сетка `.container`, верхняя планка,
шапка, навигация, карточки, подвал, адаптив. Подключена на всех страницах.

Специфичные для страницы стили лежат прямо в её `<style>` в `<head>`.
Так было в исходниках, и это оставлено как есть: страницы независимы, и
раздувать общий файл правилами, нужными одной из них, смысла нет.

Цветовая схема — тёмно-бордовый (`#7a1a1a`, `#5a0f0f`) с золотым акцентом
(`#c49a3c`, `#d9b15a`). Шрифт Inter подключается с Google Fonts.

## JavaScript

`src/assets/js/script.js` содержит три независимых блока:

1. Аккордеон FAQ — вешается на `.faq-question`;
2. Плавная прокрутка к якорям `href="#..."`;
3. Подстановка текущего года в элемент `#current-year`.

Скрипт подключён только в `news.html`. Разметки `.faq-question` сейчас нет
ни на одной странице — код аккордеона написан на вырост и просто ничего не
находит. Это не ошибка, но и не рабочая функция.

## Ресурсы

`src/assets/images/` — две фотографии: `blag-city.jpg` (757 КБ, фон баннера
на главной) и `bashun.jpg` (26 КБ, портрет на странице «Об администрации»).
Фон баннера стоит пережать: для веба 757 КБ на одно изображение много.

Иконки в карточках — встроенные SVG прямо в разметке, отдельных файлов нет.

## Что изменено при переносе

**`docs.htm` → `docs.html`.** В исходном архиве страница «Документы»
называлась `docs.htm`, а все ссылки на неё — а их 27, во всех восьми
страницах — вели на `docs.html`. Раздел был недоступен целиком. Файл
переименован; содержимое не тронуто.

**Ресурсы собраны в `assets/`.** Было три каталога в корне (`css/`, `js/`,
`images/`), стало `src/assets/{css,js,images}/`. Ссылки в HTML обновлены —
восемь `<link>` на стили, один `<script>`, два изображения.

Содержимое страниц, тексты, вёрстка и стили не менялись.

## Известные пробелы

Семь ссылок ведут на файлы, которых в проекте нет:

| Ссылка | Откуда | Что за раздел |
| --- | --- | --- |
| `finance.html` | `index.html`, карточка | Финансовое управление |
| `education.html` | `index.html`, карточка | Управление образования |
| `culture.html` | `index.html`, карточка | Управление культуры |
| `gkh.html` | `index.html`, карточка | Управление ЖКХ |
| `economy.html` | `index.html`, карточка | Управление экономики |
| `social.html` | `index.html`, карточка | Управление социальной защиты |
| `faq.html` | `news.html` | Частые вопросы |

Ссылки оставлены как есть: они отражают задуманную структуру сайта, и
подменять их заглушками — значит потерять эту информацию. Два разумных
пути, когда дойдут руки: написать страницы разделов либо временно увести
карточки на соответствующие блоки `structure.html`.

`scripts/build.sh` печатает этот список при каждой сборке, так что пробелы
не потеряются.

Отдельно: несколько ссылок в шапке ведут на `href="#"` — «Версия для
слабовидящих» и кнопка «Написать обращение» ещё не реализованы.
