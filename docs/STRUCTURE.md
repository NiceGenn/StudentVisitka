# Устройство сайта

Документ описывает, из чего состоит сайт и какие решения приняты при
переносе исходников в репозиторий.

## Страницы

Все восемь страниц самостоятельны: каждая содержит полную разметку шапки,
навигации и подвала. Общего шаблона нет, поэтому правка меню или контактов
в шапке — это правка во всех восьми файлах. Исключение — `structure.html`:
она собирается генератором из шаблона, её править руками не нужно.

| Файл | Раздел | Особенности |
| --- | --- | --- |
| `index.html` | Главная | Баннер с фото города, шесть карточек отделов, три новости, быстрые ссылки |
| `about.html` | Об администрации | Фотография руководителя (`bashun.jpg`) |
| `structure.html` | Структура | Генерируется из данных: 42 карточки подразделений с раскрытием состава, поиск и фильтры |
| `services.html` | Услуги | Муниципальные услуги |
| `news.html` | Новости | Шесть новостей карточками, вёрстка общая с главной |
| `schools.html` | Школы и сады | Перечень образовательных учреждений |
| `docs.html` | Документы | Ссылки на внешние файлы `.docx` на blagraion.ru |
| `contacts.html` | Контакты | Встроенная карта Яндекса через iframe |

## Стили

`sources/assets/css/style.css` — общая часть: сетка `.container`, верхняя планка,
шапка, навигация, карточки, подвал, адаптив. Подключена на всех страницах.

Специфичные для страницы стили лежат прямо в её `<style>` в `<head>`.
Так было в исходниках, и это оставлено как есть: страницы независимы, и
раздувать общий файл правилами, нужными одной из них, смысла нет.

Цветовая схема — монохромный сине-стальной (`#1f4e6d`, `#123449`) с более
светлым акцентом того же тона (`#3f83ad`). Шапка светлая, вес страницы
держат навигация и подвал. Шрифт Inter подключается с Google Fonts.
Все цвета — переменными в `:root`, смена схемы описана в `docs/COLORS.md`.

## JavaScript

`sources/assets/js/script.js` содержит шесть независимых блоков:

1. Аккордеон FAQ — вешается на `.faq-question`;
2. Плавная прокрутка к якорям `href="#..."`;
3. Подстановка текущего года в элемент `#current-year`;
4. Поиск и фильтр по разделам на странице «Структура»;
5. Раскрытие карточек подразделений там же;
6. Кнопка «наверх».

Скрипт подключён во всех восьми страницах: кнопка «наверх» нужна везде.
Блоки, которым не находится разметки, просто ничего не делают — так,
разметки `.faq-question` сейчас нет ни на одной странице, и код аккордеона
написан на вырост.

Кнопка «наверх» разметки в страницах не имеет: её создаёт сам скрипт и
показывает после 400 пикселей прокрутки. Стили — `.to-top` в общем файле.

Блок структуры прячет карточки атрибутом `hidden`. У `.vz-card` задан
`display: flex`, который перебивает браузерное правило для `[hidden]`,
поэтому в стилях страницы есть явное `.vz-card[hidden] { display: none }` —
без него фильтр считает совпадения, но ничего не скрывает.

## Ресурсы

`sources/assets/images/` — две фотографии: `blag-city.jpg` (757 КБ, фон баннера
на главной) и `bashun.jpg` (26 КБ, портрет на странице «Об администрации»).
Фон баннера стоит пережать: для веба 757 КБ на одно изображение много.

Иконки в карточках — встроенные SVG прямо в разметке, отдельных файлов нет.

## Визитница

Раздел «Структура» (`sources/structure.html`) — 42 карточки подразделений округа,
разложенные по шести разделам: руководство округа, отделы администрации,
управления, подведомственные учреждения, территориальные администрации,
общественные организации.

Карточка свёрнута: иконка, название, численность и описание функций.
По нажатию на шапку раскрывается состав — руководитель подразделения,
заместители, начальники отделов и остальные сотрудники, сгруппированные
по отделам.

Страница генерируется, а не пишется руками:

```
data/rukovoditeli.json     ─┐
data/podrazdeleniya.json    ├─→ tools/gen_structure.py ─→ sources/structure.html
data/foto.json             ─┘        ↑
                              tools/templates/
                              (chrome-head.html, chrome-foot.html, leaders.css)
```

`data/rukovoditeli.json` готовит `tools/import_xlsx.py` из телефонного
справочника округа. В него попадают все 287 строк справочника; у 93 руководящих
должностей стоит флаг «руководитель» — по нему карточка показывает сначала
руководителя, а под ним остальных сотрудников.

Что стоит знать при правках:

- **Описания функций написаны по типовым положениям**, а не выгружены из
  документов округа. Это заглушки правдоподобного качества, их нужно сверить
  с действующими положениями о подразделениях. На странице об этом сказано
  сноской внизу.
- Подразделения-контейнеры («Структурные подразделения администрации»,
  «Муниципальные казенные учреждения») в справочнике не имеют собственного
  руководителя. Генератор разворачивает их в отдельные карточки по отделам —
  список таких групп в константе `CONTEINERS`.
- Начальник финансового управления числится в справочнике в блоке
  руководства администрации. Чтобы карточка управления не осталась без
  руководителя, в `data/podrazdeleniya.json` есть поле `руководитель_из` —
  оно переносит человека из другого подразделения с пометкой «по должности».
- Вакансии и пометки «(декрет)», «(отпуск)», «(совместительство)» из
  справочника не выбрасываются: вакансия показывается серой строкой,
  пометка — плашкой рядом с ФИО.
- **Фотографии подставляются из `data/foto.json`**: ключ — ФИО как в
  справочнике, значение — путь от корня сайта, сами файлы лежат в
  `sources/assets/images/people/`. Сейчас там одна настоящая фотография —
  глава округа. Остальным карточка рисует нейтральный силуэт в одном из
  шести оттенков схемы; оттенок считается по ФИО, поэтому при пересборке
  у человека остаётся прежний. Случайных лиц в слоте нет и быть не должно:
  ФИО настоящие, и чужой портрет рядом с фамилией — выдумка о конкретном
  человеке.

## Что изменено при переносе

**`docs.htm` → `docs.html`.** В исходном архиве страница «Документы»
называлась `docs.htm`, а все ссылки на неё — а их 27, во всех восьми
страницах — вели на `docs.html`. Раздел был недоступен целиком. Файл
переименован; содержимое не тронуто.

**Убран мусор из `contacts.html`.** В тексте страницы были видны служебные
пометки вида `[citation:1]` — остатки инструмента, которым готовились
исходники. Десять таких пометок удалены, цифры и адреса не тронуты.

**Ресурсы собраны в `assets/`.** Было три каталога в корне (`css/`, `js/`,
`images/`), стало `sources/assets/{css,js,images}/`. Ссылки в HTML обновлены —
восемь `<link>` на стили, один `<script>`, два изображения.

Содержимое страниц, тексты, вёрстка и стили не менялись.

## Известные пробелы

Шесть ссылок ведут на файлы, которых в проекте нет:

| Ссылка | Откуда | Что за раздел |
| --- | --- | --- |
| `finance.html` | `index.html`, карточка | Финансовое управление |
| `education.html` | `index.html`, карточка | Управление образования |
| `culture.html` | `index.html`, карточка | Управление культуры |
| `gkh.html` | `index.html`, карточка | Управление ЖКХ |
| `economy.html` | `index.html`, карточка | Управление экономики |
| `social.html` | `index.html`, карточка | Управление социальной защиты |

Ссылки оставлены как есть: они отражают задуманную структуру сайта, и
подменять их заглушками — значит потерять эту информацию. Два разумных
пути, когда дойдут руки: написать страницы разделов либо временно увести
карточки на соответствующие блоки `structure.html`.

`tools/build.sh` печатает этот список при каждой сборке, так что пробелы
не потеряются.

Отдельно: несколько ссылок в шапке ведут на `href="#"` — «Версия для
слабовидящих» и кнопка «Написать обращение» ещё не реализованы.
