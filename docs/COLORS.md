# Цветовые схемы

Все цвета сайта заданы CSS-переменными в блоке `:root` файла
`src/assets/css/style.css`. В вёрстке нет ни одного фирменного цвета
литералом — только `var(--color-primary)` и подобные. Поэтому смена схемы
это замена одного блока, а не поиск по сорока значениям в девяти файлах.

## Сменить схему

```bash
python3 scripts/gen_palette.py                 # список схем
python3 scripts/gen_palette.py navy            # посмотреть блок :root
python3 scripts/gen_palette.py navy --apply    # применить
python3 scripts/gen_leaders.py                 # пересобрать визитницу
./scripts/build.sh                             # собрать dist/
```

Вернуться к исходному виду: `python3 scripts/gen_palette.py current --apply`.

## Как устроено

Переменных 29. Пять из них — фирменные, они и задают схему:

| Переменная | Где видно |
| --- | --- |
| `--color-primary` | шапка, ссылки, иконки карточек, полоска над карточкой визитницы |
| `--color-primary-dark` | навигация, верхняя планка, подвал, заголовки |
| `--color-accent` | кнопка «Написать обращение», линия под меню, акцентная черта заголовка |
| `--color-accent-light` | цифры в баннере, наведение на ссылки шапки |
| `--color-page` | фон страницы |

Остальные 24 — оттенки фонов, рамок и приглушённого текста
(`--tone-surface-*`, `--tone-line-*`, `--tone-muted-*`, `--tone-deep-*`).
Их не задают руками: генератор пересчитывает исходные тёплые оттенки в тон
схемы, сохраняя светлоту и насыщенность. Поэтому в синей схеме кремовая
плашка объявления становится холодно-голубой, а не остаётся жёлтым пятном
посреди синего сайта.

Чистые серые (`#333`, `#666`, `#999`) остались литералами: они нейтральны
и от схемы не зависят.

## Схемы

Первый набор — тёмная шапка, золотистый акцент, меняется тон:

| id | Название | Основной | Акцент | Характер |
| --- | --- | --- | --- | --- |
| `current` | Бордо (текущая) | `#7a1a1a` | `#c49a3c` | Исходная схема сайта |
| `navy` | Державный синий | `#1e3a5f` | `#b08d57` | Самая узнаваемая схема органов власти |
| `green` | Тёмно-зелёный | `#24503c` | `#b4975b` | Хвойный с бронзой, теплее синего |
| `graphite` | Графит и сталь | `#363c44` | `#7a92ab` | Нейтральный серый, акцент холодный |
| `bordeaux` | Приглушённое бордо | `#6e2f36` | `#ab936f` | Как сейчас, но заметно тише |
| `petrol` | Петроль | `#1f4a4f` | `#a8935f` | Тёмный сине-зелёный с песочным |

Второй набор — меняется не только тон, но и строение шапки или роль акцента:

| id | Название | Основной | Акцент | Чем отличается |
| --- | --- | --- | --- | --- |
| `light` | Светлая шапка | `#1c3f66` | `#2f6ba3` | Белый верх с тёмным текстом, синяя навигация |
| `flag` | Синий с красным | `#14315c` | `#9d2f35` | Акцент красный, кнопка с белым текстом |
| `teal` | Синий с бирюзой | `#17384f` | `#2f7d78` | Акцент бирюзовый вместо золота |
| `olive` | Оливково-серый | `#4a5445` | `#afa58c` | Тёплый монохром, почти без цвета |
| `stone` | Камень и медь | `#433d37` | `#ab8d6c` | Серо-коричневый с медным |

Схема `light` меняет и вёрстку шапки, поэтому к блоку `:root` добавляется
несколько правил — они лежат в поле `дополнительно` схемы и вставляются
между маркерами `НАЧАЛО ДОПОЛНЕНИЙ СХЕМЫ` и `КОНЕЦ ДОПОЛНЕНИЙ СХЕМЫ`.
При переходе на другую схему эти правила убираются автоматически.

## Контрастность

Каждая схема проверена по WCAG 2.1 AA:

- белый текст на основном цвете — не ниже 7,9:1 при норме 4,5:1;
- текст кнопки «Написать обращение» — не ниже 4,55:1 при норме 4,5:1;
- цифры баннера на основном цвете — не ниже 3,2:1 при норме 3:1
  для крупного текста.

Три схемы первого набора и две второго пришлось подсветлить в акценте,
чтобы дотянуть до нормы. Если будете задавать свои цвета — проверьте
контраст: на сайте есть ссылка «Версия для слабовидящих», и требования
к доступности для органов власти обязательны.

## Добавить свою схему

Дописать объект в массив `схемы` файла `data/palitry.json`:

```json
{
  "id": "myscheme",
  "имя": "Моя схема",
  "описание": "Одна строка про характер",
  "основной": "#2b4a6f",
  "тёмный": "#1c3352",
  "акцент": "#a8845c",
  "акцент_светлый": "#c0a077",
  "фон": "#f6f7f9",
  "тон": 210
}
```

`тон` — угол оттенка от 0 до 360 для пересчёта нейтралей: 30 тёплый
песочный, 140 зелёный, 210 синий. Поле `дополнительно` необязательное —
туда кладут CSS, если схема меняет не только цвета.
