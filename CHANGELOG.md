# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.1.0] — 2026-09-04

### Добавлено

- Раздел **«Визитница»** (`src/leaders.html`): 42 карточки подразделений
  округа в шести разделах. В карточке — описание функций подразделения,
  перечень направлений работы, руководитель, заместители и начальники
  отделов с кабинетами, телефонами и почтой.
- Поиск по фамилии, должности и подразделению плюс фильтр по разделам —
  четвёртый блок в `src/assets/js/script.js`.
- Данные визитницы: `data/rukovoditeli.json` (руководители из телефонного
  справочника округа) и `data/podrazdeleniya.json` (разделы страницы и
  описания функций подразделений).
- `scripts/import_xlsx.py` — импорт телефонного справочника из `.xlsx`;
  отбирает только руководящие должности.
- `scripts/gen_leaders.py` и `scripts/templates/` — сборка страницы
  «Визитница» из данных и шаблонов.
- Пункт «Визитница» в навигации и подвале всех страниц.
- `scripts/build.sh` предупреждает, если данные новее собранной страницы.

### Исправлено

- Из `contacts.html` убраны десять служебных пометок вида `[citation:1]`,
  которые выводились в текст страницы.

### Известные ограничения

- Описания функций подразделений составлены по типовым положениям органов
  местного самоуправления и требуют сверки с действующими положениями
  округа. На странице об этом сказано сноской.
- Фотографий руководителей в исходных данных нет — вместо аватара выводятся
  инициалы.

## [1.0.0] — 2026-09-04

Первая версия в репозитории. Исходники сайта, до этого существовавшие только
в виде архива `obrazovanie-site.zip`, приведены к воспроизводимой структуре.

### Добавлено

- Каталог `src/` с восемью страницами сайта и общими ресурсами в `src/assets/`.
- Скрипт сборки `scripts/build.sh`: собирает `dist/`, проверяет внутренние
  ссылки и упаковывает архив релиза в `release/`.
- GitHub Actions: публикация на GitHub Pages и сборка релиза по тегу `v*`.
- Документация: `README.md`, `docs/STRUCTURE.md`, `docs/DEPLOY.md`.
- Файлы памяти для Claude Code: `CLAUDE.md` и `.claude/settings.json`.

### Исправлено

- `docs.htm` переименован в `docs.html`. Страница «Документы» была недоступна:
  на неё ссылались 27 ссылок во всех восьми страницах сайта, и все они вели
  на несуществующий `docs.html`.

### Изменено

- Ресурсы перенесены из `css/`, `js/`, `images/` в единый каталог
  `src/assets/{css,js,images}/`; ссылки на них в HTML обновлены.

### Известные ограничения

- Семь ссылок на карточках главной страницы и в новостях ведут на ещё
  не написанные страницы разделов. Список — в `docs/STRUCTURE.md`.
