# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-04

Первая версия в репозитории. Исходники сайта, до этого существовавшие только
в виде архива `obrazovanie-site.zip`, приведены к воспроизводимой структуре.

### Добавлено

- Каталог `src/` с восемью страницами сайта и общими ресурсами в `src/assets/`.
- Скрипт сборки `scripts/build.sh`: собирает `dist/`, проверяет внутренние
  ссылки и упаковывает архив релиза в `release/`.
- GitHub Actions: публикация на GitHub Pages и сборка релиза по тегу `v*`.
- Документация: `README.md`, `docs/STRUCTURE.md`, `docs/DEPLOY.md`.
- Файлы памяти для Claude Code: `CLAUDE.md` и `.claude/settings.json`.

### Исправлено

- `docs.htm` переименован в `docs.html`. Страница «Документы» была недоступна:
  на неё ссылались 27 ссылок во всех восьми страницах сайта, и все они вели
  на несуществующий `docs.html`.

### Изменено

- Ресурсы перенесены из `css/`, `js/`, `images/` в единый каталог
  `src/assets/{css,js,images}/`; ссылки на них в HTML обновлены.

### Известные ограничения

- Семь ссылок на карточках главной страницы и в новостях ведут на ещё
  не написанные страницы разделов. Список — в `docs/STRUCTURE.md`.
