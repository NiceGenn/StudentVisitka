# Передача проекта

Состояние на 4 сентября 2026 года, версия 1.11.0. Что готово, что нет и что
нужно сделать владельцу репозитория.

## Коротко

Сайт администрации Благовещенского муниципального округа: восемь статических
страниц, без зависимостей и бэкенда. Собирается одной командой, публикуется
копированием папки. Работа велась в ветке
`claude/project-structure-release-vkf2gr`.

## Что нужно от владельца репозитория

**Включить GitHub Pages.** Settings → Pages → Build and deployment →
Source: **GitHub Actions**. Без этого workflow публикации падает с ошибкой
`Get Pages site failed` — она и даёт красный крестик у коммитов. Создать
сайт из workflow нельзя: у `GITHUB_TOKEN` нет таких прав. После включения
сайт откроется по адресу `https://nicegenn.github.io/StudentVisitka/`.

**Переименовать репозиторий в `StudentVisitka`.** Settings → General →
Repository name → StudentVisitka → Rename. Ссылки в документации уже
указывают на новое имя, поэтому до переименования они не работают.
После — обновить свой локальный клон:

```bash
git remote set-url origin https://github.com/NiceGenn/StudentVisitka.git
```

Старые ссылки GitHub перенаправляет автоматически, но перенаправление
пропадёт, если завести новый репозиторий со старым именем.

**Решить с веткой.** Вся работа лежит в `claude/project-structure-release-vkf2gr`,
ветки `main` в репозитории нет. Либо создать `main` из текущей и сделать её
основной, либо оставить как есть — workflow публикует и с той, и с другой.

**Выбрать схему и убрать панель.** На сайте временно висит переключатель
цветовых схем — кнопка «Цветовая схема» в правом нижнем углу. Она нужна,
чтобы выбрать оформление на живом сайте, а не по скриншотам. После выбора:

```bash
python3 tools/gen_palette.py <id> --apply   # закрепить схему
python3 tools/gen_themes.py --off           # убрать панель без следа
python3 tools/gen_structure.py && ./tools/build.sh
```

Посетителю сайта органа власти выбирать палитру незачем — панель должна
уйти до сдачи работы.

**Цветовая схема.** Сейчас стоит «Сталь и лён» — монохромный сине-стальной
на светлом фоне. Если понадобится другая, в `docs/COLORS.md` ещё шестнадцать
готовых вариантов, включая исходный бордовый; применяются одной командой.

## Что не сделано и почему

**Шесть страниц разделов не написаны.** `finance.html`, `education.html`,
`culture.html`, `gkh.html`, `economy.html`, `social.html` — карточки на
главной. Ссылки на них оставлены намеренно —
они отражают задуманную структуру сайта. `tools/build.sh` печатает список
при каждой сборке, так что они не потеряются.

**Описания функций подразделений не сверены с документами округа.**
Составлены по типовым положениям органов местного самоуправления. Текст
правдоподобный, но это заглушка: на странице стоит сноска. Сверка с
действующими положениями — отдельная задача. Тексты лежат в
`data/podrazdeleniya.json`, править их удобно.

**`blag-city.jpg` весит 757 КБ.** Фон баннера главной страницы заметно
замедляет её на мобильном интернете. Пережать стоит, но отдельной задачей.

**«Версия для слабовидящих» и «Написать обращение» не работают.** В шапке
это ссылки `href="#"`. Для сайта органа власти первое обязательно.

**Фотографий, кроме главы округа и Уварова Г. Г., нет.** В справочнике их не было. Слот под
фотографию в карточках готов: положить файл в
`sources/assets/images/people/`, дописать строку в `data/foto.json`
(ключ — ФИО, значение — путь от корня сайта) и пересобрать страницу. Пока
фотографии нет, рисуется нейтральный силуэт. Подставлять вместо неё
случайные портреты нельзя: ФИО настоящие, и чужое лицо рядом с фамилией —
выдумка о конкретном человеке.

## Как продолжить работу

```bash
git clone https://github.com/NiceGenn/StudentVisitka.git
cd StudentVisitka
git checkout claude/project-structure-release-vkf2gr

python3 -m http.server 8000 --directory sources   # посмотреть сайт
./tools/build.sh                                  # собрать и проверить ссылки
```

Правится только `sources/`. После правок `data/` нужно пересобрать обе
страницу: `python3 tools/gen_structure.py`. Файл `sources/structure.html`
руками не редактируется — он генерируется целиком.

Новая версия: раздел в `CHANGELOG.md`, затем тег `vX.Y.Z` — GitHub Actions
соберёт архив и создаст релиз. Подробности в `docs/DEPLOY.md`.
